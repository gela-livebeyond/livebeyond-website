# LiveBeyond website

The LiveBeyond marketing site, redesigned in the BeyondClock deck style (November 2026).

- `index.html`: the whole page (layout, styles and the small script for the menu, sample report and enquiry form)
- `images/`: every image the page uses
- `CLAUDE.md`: brand and working rules that Claude Code follows automatically

## Making a change (for the team)

1. Open Claude Code at claude.ai/code and pick the `livebeyond-website` repository.
2. Describe the change in plain words, e.g. "Swap the hero image for the cycling couple" or "Add a new FAQ about turnaround time." Attach images if needed.
3. Claude makes the change on a new branch and opens a pull request.
4. Open the Vercel preview link on that pull request. Check it on desktop and on your phone.
5. Happy? Click **Merge** and the live site updates in about a minute. Not yet? Keep prompting in the same chat.

## Previewing locally

Double-click `index.html` to open it in a browser. No install needed.
